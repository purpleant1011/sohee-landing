# 소희 랜딩 리뉴얼 구현 계획

**Goal:** 소희를 월 구독으로 고용하는 마케팅 직원으로 이해하고, 홍보부터 예약과 성과까지 이어지는 가치를 체험하는 독립 랜딩.
**Architecture:** 기존 마케팅 소스와 캐릭터를 근거로 독립 정적 페이지를 구성한다. /landing 경로에서 모든 로컬 자산과 상호작용이 동작한다.
**Tech Stack:** HTML, CSS, ES modules, Node 내장 테스트 및 정적 빌드. 추가 런타임 의존성 없음.
**Spec:** PRODUCT.md, DESIGN.md.

## Constraints
로그인 없음. 실제 배포 금지. 가짜 후기·성과·가입 성공 없음. 원본 앱 수정 없음. 키·고객 데이터 반입 없음.
